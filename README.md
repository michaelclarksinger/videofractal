# Video Fractal

This project provides a simple web interface for generating fractal-style videos. Upload a source video and choose an effect to create mirrored or kaleidoscopic patterns.

## Requirements

- Python 3.12+
- `flask`, `moviepy`, `opencv-python`

Install dependencies with:

```bash
pip install flask moviepy opencv-python
```

## Usage

Run the Flask app:

```bash
python app.py
```

Open your browser to `http://localhost:5000` and upload a video file. Choose the desired effect and parameters to generate a processed clip.
